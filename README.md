# esp32_sushka_mosfet

Прошивка ESP32 для сушильного шкафа **Shkaf R.032-mosfet**: нагрев и вентиляция через MOSFET, датчик температуры и влажности AM2305, управление с дисплея Nextion.

Скетч лежит в `main/` (Arduino IDE, несколько `.ino` в одной папке). Экран — в `ekran/` (Nextion Editor, `sushka.HMI`). Выводы заданы в `main/2_define.ino`.

## GPIO

| GPIO | Имя в коде | Направление | Назначение |
| --- | --- | --- | --- |
| 16 | `HEATER_PIN` | выход | Затвор MOSFET нагревателя. Включение уровнем 0 |
| 17 | `VENT_PIN` | выход | Затвор MOSFET вентиляции. Включение уровнем 0 |
| 23 | `DEVICE_PIN` | выход | Питание устройства: 1, пока цикл сушки идёт; 0 в простое и после останова |
| 15 | `DHTPIN` | вход | Данные AM2305 (в коде тип `DHT22`) |
| 33 | `NEXTION_RX` | UART1 RX | К TX дисплея Nextion |
| 32 | `NEXTION_TX` | UART1 TX | К RX дисплея Nextion |
| 1 | UART0 TX | выход | Отладка `Serial`, 115200 бод (USB) |
| 3 | UART0 RX | вход | Отладка `Serial` (USB) |

Дисплей открывается как `HardwareSerial(1)` на 9600 бод, 8N1, RX = GPIO 33, TX = GPIO 32.

Питание и земля датчика и дисплея в коде не задаются: AM2305 — VCC, GND и DATA на GPIO 15; Nextion — 5 В, GND и две линии UART.

### Уровни выходов

Нагрев и вентиляция включаются низким уровнем:

| Константа | Уровень | Состояние нагрева и вентиляции |
| --- | --- | --- |
| `RELAY_ON` | 0 | включено |
| `RELAY_OFF` | 1 | выключено |

`DEVICE_PIN` работает наоборот: `DEVICE_ON` = 1, `DEVICE_OFF` = 0.

После включения контроллера `setUpRelay()` ставит GPIO 16 и GPIO 17 в 1 (нагрев и вентиляция выключены), GPIO 23 в 0.

Дальше GPIO 23:

- `STARTING` с дисплея — сразу 1;
- `STOPPING` (кнопка стоп или таймер дошёл до 0) — 0 вместе с выключением нагрева и вентиляции.

Ручные команды `VENT_ON` и `VENT_OFF` на GPIO 23 не влияют.

## Режимы

| Код | Состояние | Что делает |
| --- | --- | --- |
| 0 | `NONE` | простой после включения, GPIO 23 = 0 |
| 1 | `STARTING` | с дисплея приняты температура и время, GPIO 23 = 1 |
| 2 | `WARMUP` | нагрев включён, вентиляция выключена, пока температура ниже уставки |
| 3 | `RUNNING` | уставка достигнута, идёт таймер в минутах |
| 4 | `COOLDOWN` | объявлен, в цикле не используется |
| 5 | `STOPPING` | GPIO 16 и 17 выключаются, GPIO 23 = 0 |
| 6 | `STOPPED` | цикл завершён, экран возвращается на `p_set` |

Переход `STARTING` → `WARMUP` происходит, только если текущая температура ниже уставки.

Гистерезис нагрева — `TRASHOLE_MIN` = 3 °C. В режиме `RUNNING`:

- температура ≥ уставки и нагрев включён → нагрев выкл, вентиляция вкл;
- температура ≤ уставка − 3 °C и нагрев выключен → нагрев вкл, вентиляция выкл.

Датчик опрашивается каждые 2 секунды. Показания отбрасываются, если чтение не удалось или температура выше 100 °C.

## Команды с Nextion

Строка с дисплея читается в `nextion_action`. Поля разделены `|`, номер поля берёт `Nextion_readVal()`.

| Фрагмент строки | Действие |
| --- | --- |
| `VENT_ON` | вентиляция включена (GPIO 17 = 0) |
| `VENT_OFF` | вентиляция выключена (GPIO 17 = 1) |
| `STARTING` | поле 1 — минуты, поле 2 — температура, °C; GPIO 23 = 1 |
| `STOPPING` | таймер обнуляется, нагрев и вентиляция выключаются, GPIO 23 = 0 |

На дисплей уходят температура (`run_temp`), влажность (`run_humi`) и оставшееся время (`run_time`) на страницах `p_set` и `p_live`.
